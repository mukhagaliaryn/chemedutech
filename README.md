# ChemEduTech

Химиядан онлайн білім беру платформасы және виртуалды (симуляторлық) зертхана.
Докторлық диссертациялық жоба: болашақ химия мұғалімдеріне арналған курс,
2D интерактивті зертханалық жұмыстар және педагогикалық экспериментке арналған
зерттеу деректерін жинау.

Стек: Django 6, PostgreSQL, Tailwind CSS 4, Alpine.js. Интерфейс тілдері: қазақ
(негізгі), орыс, ағылшын.

## Іске қосу

```bash
pip install -r requirements/dev.txt                  # prod: requirements/base.txt
npm install && npm run build:css && npm run vendor   # Tailwind + Alpine
cp .env.example .env                                  # дерекқор параметрлері
python manage.py migrate
python manage.py compilemessages -l kk -l ru
python manage.py seed_course                          # курс қаңқасы, 1-тақырып
python manage.py createsuperuser
python manage.py runserver
```

CSS-ті әзірлеу кезінде: `npm run watch:css`.

## Не дайын

- **1-тақырыптың зертханалық жұмысы (4 тәжірибе)** техникалық тапсырма бойынша:
  1. Сутегіні алу және жинау (Zn + HCl, суды ығыстыру, тазалығын тексеру анимациясы)
  2. Оттегіні алу (H₂O₂ катализаторсыз → MnO₂ қатысында, жылдамдықтарды салыстыру, шамшырақ сынағы)
  3. Судың электролизі (электролит таңдау, V(t) графигі, H₂ : O₂ = 2 : 1)
  4. H₂O₂ ыдырау жылдамдығы (А және В пробиркалары, график, теориялық шегі)
- Құралдарды тышқанмен/саусақпен сүйреп қою немесе «Құралды таңдау» батырмасы.
- Қадамдар ретін бақылау, қауіпсіздік ескертулері, қажетсіз құралдар (спирт шамы, мыс, KMnO₄, айнымалы ток көзі) туралы түсіндірме.
- Зертханалық журнал, тәжірибені аяқтау, талдау тапсырмасы (жабық + ашық сұрақтар).
- **Зерттеу қабаты:** әр әрекет логқа жазылады (`LabEvent`), талпыныс метрикалары
  (уақыт, рет қателері, қауіпсіздік ескертулері, қате құралдар, кеңестер, әр қадамға
  кеткен уақыт, журнал мен талдау нәтижесі). Бақылау/эксперименттік топ бойынша
  орташа мәндер және CSV экспорты: `/research/`.

## Жаңа тәжірибе қосу

Әр тәжірибе — үш файл:

| Файл | Мазмұны |
|---|---|
| `apps/labs/experiments/<lab>/<name>.py` | `ExperimentSpec`: құралдар, командалар реті, ескертулер, журнал, талдау сұрақтары, физикалық параметрлер |
| `apps/labs/templates/labs/scenes/<name>.html` | 2D SVG жұмыс үстелі |
| `static/js/lab/experiments/<name>.js` | Анимация және физикалық модель (`ChemLab.scene(...)`) |

Жалпы логика (рет, ескертулер, журнал, логтау) `static/js/lab/engine.js` ішінде.
Барлық мәтін ағылшынша `gettext_lazy` арқылы жазылады, кейін:

```bash
python manage.py makemessages -l kk -l ru --ignore=node_modules
# locale/*/LC_MESSAGES/django.po аудару
python manage.py compilemessages -l kk -l ru
```

## Демо-пайдаланушылар (тек әзірлеуге)

`seed_course` пайдаланушы жасамайды. Студентке зерттеу тобын (`cohort`) админкада
немесе `/admin/accounts/user/` тізімінде тағайындаңыз.

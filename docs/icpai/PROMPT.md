# Claude Code-қа арналған промпттар — ICPAI 8 бөлімі

Файлдар жобаның түбіріне көшірілгеннен кейін (`docs/icpai/…`, `docs/TASKS.md`, `CLAUDE.md`) Claude Code-та
жаңа сессияны төмендегі **бастау промптымен** ашыңыз. Кейін әр STEP-ті **STEP промптымен** бөлек сессияда жүргізіңіз.

---

## 1. Бастау промпты (бір рет, STEP-28)

```
ChemEduTech жобасына ICPAI авторлық моделінің 8 бөлімін қосамыз. Код жазбас бұрын мыналарды толық оқы:

1. CLAUDE.md, docs/ARCHITECTURE.md (әсіресе §3–§5, §11 журналы), docs/TASKS.md (соңындағы «3-кезең: ICPAI»).
2. docs/icpai/SPEC.md — 8 бөлімнің техникалық сипаттамасы, модельдер, 80% ережесі, ЖИ режимдері, ашық сұрақтар О-1…О-9.
3. docs/icpai/source/guide.md — автордың Word нұсқаулығының мәтіні (түпнұсқа: docs/icpai/source/ICPAI_нұсқаулық.docx).
   Бөлімдер `## [@S0-INTRO]`, `## [@S1]` … `## [@S8]` белгілерімен бөлінген. Суреттер docs/icpai/source/media/
   (не бейнелейтіні — SPEC.md «Нұсқаулықтағы суреттер» кестесінде) — қажет болса Read-пен ашып қара.

Содан кейін STEP-28-ді орында:
- ui/tests.py-дағы 3 ескірген тестті түзет (толық тест жиынтығы өтуі керек).
- SPEC.md мен guide.md-ні салыстырып, қайшылықтар мен түсініксіз жерлерді тізім етіп маған шығар (код жазбай).
  Әр пункт үшін: guide.md белгісі, мәселе, сенің ұсынысың.
- ARCHITECTURE.md §2 және §8-ге жаңа апптар (ai, pedagogy, programme) мен беттердің жобасын қос.

Ережелер: мазмұнды (мәтін, сұрақ, кілт, батырма атауы, өріс атауы) нұсқаулықтан ал, ойдан құрастырма.
Бар зерттеу деректері мен логикасын өзгертпе. Келісілмеген архитектуралық шешім болса — алдымен сұра.
Маған қазақша жауап бер.
```

## 2. STEP промпты (STEP-29 … STEP-40, әрқайсысына жаңа сессия)

`NN` орнына STEP нөмірін қойыңыз:

```
docs/TASKS.md-дегі STEP-NN-ді орында.

Бастамас бұрын: CLAUDE.md, docs/icpai/SPEC.md-нің STEP-те көрсетілген бөлімдері және docs/icpai/source/guide.md-нің
STEP-те көрсетілген белгілері (`grep -n '@SX' docs/icpai/source/guide.md`, сол белгіден келесі `## [@` белгісіне
дейін толық оқы). STEP-те сурет аталса — docs/icpai/source/media/-дан ашып қара (бұл концепт, дизайн — біздің жүйе).

Жұмыс тәртібі:
1. Алдымен жоспар: қандай модель/миграция/сервис/бет/тест жасалады, guide.md-ден қандай мазмұн алынады.
   SPEC.md-дегі «⚠» шешімге тиетін болса — әдепкі нұсқаны ал, баптауға шығар, жоспарда атап өт.
2. Код: services/ — жазу, selectors/ — оқу, views жұқа; қабат ережесі; барлық интерфейс жолы ағылшынша gettext
   (kk аудармасы — нұсқаулықтағы мәтін), мазмұн seed-те қазақша; ЖИ — тек apps/ai арқылы, тесттерде fake.
3. Соңында: python manage.py test apps ui · makemigrations --check · ruff check · makemessages/compilemessages ·
   TASKS.md-дегі STEP-NN құсбелгілері · ARCHITECTURE.md §11-ге D-жазба · SPEC.md-ге өзгерген шешім.
4. Есеп (қазақша, қысқа): не жасалды, қандай шешім қабылданды, нұсқаулықтан қай мазмұн енгізілді,
   не қалды / маған қандай сұрақ бар.
```

## 3. Пайдалы қосымша промпттар

**Бөлімді браузерде тексеру** (STEP соңында):
```
seed_icpai және seed_course-ты іске қос, тест студенті мен мұғалімін жаса, STEP-NN-де қосылған беттерді
студент және мұғалім ретінде толық өтіп шық (desktop 1440 және mobile 390). Әр бетті guide.md-нің тиісті
белгісімен және SPEC.md-мен салыстырып, сәйкессіздіктерді тізіп бер, содан кейін түзет.
```

**ЖИ промптын тексеру** (STEP-32 және ЖИ қолданатын STEP-тер):
```
apps/ai/prompts/<mode>.py промптын guide.md-дегі талаптармен салыстыр (@S4-AI, @S5 III, @S6 III, @S8 III).
ANTHROPIC_API_KEY бар болса, 5 нақты сценарийді (оның ішінде «кезеңді толық жазып бер» деген сұрау және
қате химиялық теңдеу) management командасы арқылы бір рет нақты API-мен жүргізіп, жауаптарды маған көрсет.
Тесттерге нақты API шақыруын қоспа.
```

**Нұсқаулық жаңарса** (автор жаңа Word жіберсе):
```
docs/icpai/source/ICPAI_нұсқаулық.docx жаңартылды. pandoc-пен guide.md-ні қайта жасап
(`pandoc … -t gfm --wrap=none --extract-media=.`), @S белгілерін бұрынғы орындарына қайта қой,
ескі және жаңа нұсқаның айырмасын бөлімдер бойынша қысқаша шығар және қай STEP-терге әсер ететінін айт.
```

# Claude Code-қа бастапқы промпт

Төмендегі мәтінді жоба түбірінде ашылған Claude Code сессиясына көшіріп қойыңыз.
Әр келесі STEP үшін соңғы жолдағы нөмірді ауыстыру жеткілікті.

---

Сен ChemEduTech жобасында жұмыс істейсің — болашақ химия мұғалімдеріне арналған LMS және
2D виртуалды зертхана (докторлық диссертациялық жоба). Жоба прототип күйінде: Django 6,
PostgreSQL, Tailwind 4, Alpine.js, 1-тақырыптың 4 зертханалық тәжірибесі жұмыс істейді.

Енді прототипті толыққанды LMS архитектурасына көшіреміз. Бастамас бұрын мына құжаттарды
толық оқы:

1. `CLAUDE.md` — жоба ережелері мен конвенциялары
2. `docs/ARCHITECTURE.md` — архитектура, рөлдер, модельдер, gating және бағалау логикасы, техникалық шешімдер
3. `docs/TASKS.md` — STEP-тер бойынша жұмыс жоспары

Жұмыс тәртібі:
- Тек мен көрсеткен STEP-ті орында. Бастамас бұрын қысқа жоспар жаз (қай файлдар, қандай модельдер/сервистер), сосын код.
- Архитектурада жазылмаған маңызды шешім керек болса — тоқта да, сұра.
- Код, `verbose_name`, `gettext` жолдары — ағылшынша; маған жауаптарыңды қазақша жаз.
- Бизнес-логика `services/`-те, оқу сұраулары `selectors/`-те; views жұқа.
- Зертхана симуляторының логикасын (`apps/labs/engine`, `experiments/`, сахналар, `engine.js`) сұрамасам өзгертпе.
  Зерттеу логтарын (LabEvent, QuizAttempt, AttemptAnswer) жоятын немесе бұрмалайтын өзгеріс жасама.
- STEP соңында: `python manage.py check`, тесттер, `makemigrations --check`, `ruff check .` — бәрі таза болсын.
  Сосын қысқа есеп: не жасалды, қандай шешімдер қабылданды, не қалды. Git коммит: `STEP-XX: <қысқаша>`.
- UI беттері «ChemEduTech UI» дизайн артефактындағы макеттерге сәйкес болсын; түстер мен токендер — «ChemEduTech Design System»-нен
  (сілтемелер `CLAUDE.md`-де; макеттердің скриншоттарын мен өзім беремін).

Бастайық: **STEP-00**, содан кейін **STEP-01**.
